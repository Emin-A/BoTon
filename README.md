# BoTon — автоматическая рассылка заданий специалистам

Система для заведующего отделением: ежедневно собирает задания из Google Таблицы,
рассылает врачам печатные листы заданий (формат A4), отмечает отправку в таблице
и присылает сводный отчёт.

## Как работает

- Каждые 5 минут (07:00–23:00 МСК) проверяет таблицу заданий.
- Формирует врачу лист заданий: клиенты, ID, список задач, место для отметок.
- Отправляет письмо специалисту (plain-text, удобно печатать).
- Пишет отметку об отправке в колонку «Комментарии» таблицы заданий.
- Ведёт журнал `BoTon_Log` (защита от повторных отправок).
- Если отправка зависла (статус PENDING старше 5 минут) — повторяет автоматически.
- После успешной рассылки шлёт отчёт заведующему с детализацией по врачам.
- В конце каждого письма — четверостишие: генерируется через LLM API,
  а пока API-ключ не задан — берётся из резервной подборки готовых стихов.

## Структура

- `main.py` — точка входа.
- `config.py` — настройки (все личные значения читаются из секретов).
- `utils.py` — время, нормализация, разбор дат.
- `google_sheets.py` — Google Sheets API, пакетная запись, retry.
- `log_store.py` — журнал `BoTon_Log`.
- `doctors.py` — справочник врачей, нечёткий поиск по ФИО.
- `tasks.py` — отбор строк, автоопределение колонок по заголовкам.
- `mailer.py` — SMTP, текст письма-листа, генерация стихов.
- `sender.py` — рассылка, защита от дублей, отметки в таблице.
- `report.py` — отчёт заведующему.

## Необходимые секреты GitHub (Settings → Secrets and variables → Actions)

| Секрет | Назначение |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT` | JSON сервисного аккаунта Google |
| `TASKS_SPREADSHEET_ID` | ID таблицы заданий |
| `DOCTORS_SPREADSHEET_ID` | ID таблицы специалистов |
| `LOG_SPREADSHEET_ID` | ID таблицы с листом `BoTon_Log` |
| `TEST_EMAIL` | Тестовый адрес |
| `REPORT_EMAIL` | Адрес заведующего для отчётов |
| `RESERVE_EMAILS` | Резервные адреса через запятую |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL` | Отправка писем |
| `POEM_API_KEY` | Необязательно: ключ Groq для генерации стихов |

## Запуск

- Автоматически: по расписанию (каждые 5 минут, 07:00–23:00 МСК).
- Вручную: Actions → «BoTon - Рассылка заданий» → Run workflow.
  - `test_to_reserve=true` — тестовый прогон на резервные адреса.
  - `force_resend=true` — принудительная повторная отправка.

Перед боевым запуском всегда делайте тестовый прогон (`test_to_reserve=true`).
